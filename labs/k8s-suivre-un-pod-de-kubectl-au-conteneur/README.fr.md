# Suivre un Pod de kubectl au conteneur

Lab guidé du module **Architecture** de la formation Kubernetes : d'un
`kubectl create` à un conteneur qui tourne, lire dans les événements quel
composant agit à chaque étape.

| | |
|---|---|
| Cible | `k8s-kind.lab`, cluster kind `architecture`, un control plane et trois workers (Kubernetes 1.37) |
| Durée | environ 20 minutes |
| Page associée | [Architecture Kubernetes, section Mettre en pratique](https://www.stephane-robert.info/docs/conteneurs/orchestrateurs/kubernetes/architecture/#mettre-en-pratique) |

```bash
dsoxlab run   k8s-suivre-un-pod-de-kubectl-au-conteneur
dsoxlab check k8s-suivre-un-pod-de-kubectl-au-conteneur
```
