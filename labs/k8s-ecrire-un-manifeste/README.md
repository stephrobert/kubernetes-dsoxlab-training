# Write and validate a manifest

Guided lab of the **Deploy your applications** module of the Kubernetes course:
generate, complete, validate on the server side and apply a multi-document file
that names its namespace, then correct an existing Deployment in place.

| | |
|---|---|
| Target | `k8s-kind.lab`, kind cluster `lab`; the lab sets up the `commandes` namespace and a faulty Deployment |
| Duration | about 30 minutes |
| Related page | [Écrire des Manifests, Mettre en pratique section](https://www.stephane-robert.info/docs/conteneurs/orchestrateurs/kubernetes/ecrire-manifests/#mettre-en-pratique) |

```bash
dsoxlab run   k8s-ecrire-un-manifeste
dsoxlab check k8s-ecrire-un-manifeste
```
