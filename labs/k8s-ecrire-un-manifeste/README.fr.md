# Écrire et valider un manifeste

Lab guidé du module **Déployer ses applications** de la formation Kubernetes :
générer, compléter, valider côté serveur et appliquer un fichier multi-documents
qui nomme son namespace, puis corriger en place un Deployment existant.

| | |
|---|---|
| Cible | `k8s-kind.lab`, cluster kind `lab` ; le lab pose le namespace `commandes` et un Deployment fautif |
| Durée | environ 30 minutes |
| Page associée | [Écrire des Manifests, section Mettre en pratique](https://www.stephane-robert.info/docs/conteneurs/orchestrateurs/kubernetes/ecrire-manifests/#mettre-en-pratique) |

```bash
dsoxlab run   k8s-ecrire-un-manifeste
dsoxlab check k8s-ecrire-un-manifeste
```
