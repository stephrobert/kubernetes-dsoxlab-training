# Épreuve du niveau 1 : livrer et mettre à jour une application

Épreuve de fin de niveau de la formation Kubernetes : d'après un cahier des
charges qui ne nomme aucun objet Kubernetes, livrer une vitrine puis la passer
à la version suivante sans coupure. Notée sur l'état final (seuil 70, quatre
exigences critiques).

| | |
|---|---|
| Cible | `k8s-kind.lab`, cluster kind `boutique` (Kubernetes 1.37) |
| Durée | environ 45 minutes |
| Page associée | [Formation Kubernetes](https://www.stephane-robert.info/docs/conteneurs/orchestrateurs/kubernetes/) (la page de l'épreuve est en cours d'écriture) |

```bash
dsoxlab run   k8s-epreuve-livrer-et-mettre-a-jour
dsoxlab check k8s-epreuve-livrer-et-mettre-a-jour
```
