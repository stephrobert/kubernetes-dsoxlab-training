# Create or apply: apply, server-side apply and prune

Guided lab of the **Deploy your applications** module of the Kubernetes course:
apply a folder with subfolders, spare the replicas of an autoscaler, take over a
field with server-side apply, and prune without damage.

| | |
|---|---|
| Target | `k8s-kind.lab`, kind cluster `lab`; the lab sets up the `livraisons` namespace and the `~/livraisons/appli/` folder |
| Duration | about 30 minutes |
| Related page | [kubectl create and apply, Mettre en pratique section](https://www.stephane-robert.info/en/docs/conteneurs/orchestrateurs/kubernetes/kubectl-create-apply/) |

```bash
dsoxlab run   k8s-creer-ou-appliquer
dsoxlab check k8s-creer-ou-appliquer
```
