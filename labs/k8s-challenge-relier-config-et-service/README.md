# Wire a ConfigMap, a Secret and a Service to a Deployment

Challenge of the **Basic resources** module of the Kubernetes course, with no
guidance, graded on the state of the cluster (pass mark 70). It uses the moves
of the CKAD *Application Environment, Configuration and Security* domain.

| | |
|---|---|
| Target | `k8s-kind.lab`, kind cluster `boutique` (Kubernetes 1.37) |
| Duration | about 30 minutes |
